# HomeStock

**HomeStock** is a MERN-based household inventory and budget management platform developed for IT3040 – IT Project Management (Assignment 5).

## Team Members
- W.G.P.N. Fernando – Inventory Module
- B.M.S.S.N.B Basnayake – Order & Purchase Module
- R.R.P.W.M.R.Y.L Galagoda – User Management
- A.K.A.A Alawaththa – Budget Management

## Features
- Manage inventory items (CRUD)
- Create and manage purchase orders
- Track family budget
- Manage user accounts
- Role-based access for different users

## Tools Used
- MongoDB
- Express.js
- React.js
- Node.js
- GitHub
- Azure Boards
- SonarQube
- Selenium IDE

## How to Run
1. Clone the repository
2. Run `npm install` in both `client` and `server` folders
3. Start MongoDB
4. Run `npm start` for both backend and frontend
